# 주식 차트분석 앱 제품 로드맵

작성일: 2026-07-14

## 1. 핵심 차트 및 보조 지표

목표: 사용자가 차트를 빠르게 탐색하고, 주요 기술적 지표를 켜고 끄면서 매매 시나리오를 확인할 수 있게 한다.

### 1차 구현

- 인터랙티브 캔들 차트
  - 기간 선택: 1D, 1W, 1M, 3M
  - 좌우 이동 가능한 OHLCV 차트
  - 거래량 하단 표시
- 지표 토글
  - SMA
  - EMA
  - RSI
  - MACD
  - 볼린저 밴드

### 고도화

- 핀치 줌인/줌아웃
- 크로스헤어
- 캔들 상세 툴팁
- 대용량 시계열 렌더링 최적화
- 향후 `react-native-skia` 또는 전용 차트 엔진 검토

## 2. 포트폴리오 및 리스크 분석

목표: 단순 차트 앱이 아니라 실제 포트폴리오 리스크를 판단할 수 있는 도구로 확장한다.

### 1차 구현

- 관심종목 기반 포트폴리오 입력
- 종목별 비중 입력
- 포트폴리오 수익률 시계열 계산
- 벤치마크 대비 베타 계산
  - KOSPI
  - S&P 500
- 자산 간 상관관계 매트릭스

### 고도화

- 목표 베타 기반 비중 시뮬레이터
- 상관관계 히트맵
- 변동성, 최대 낙폭, VaR 지표
- 리밸런싱 제안

## 3. 백테스팅 및 실시간 처리

목표: 사용자가 직접 조건을 만들고, 과거 데이터로 검증한 뒤 실시간 알림까지 연결한다.

### 1차 구현

- 조건식 빌더
  - RSI 이하/이상
  - MACD 골든크로스/데드크로스
  - 이동평균선 돌파
  - 가격 조건
- 백테스트 리포트
  - 총 수익률
  - 승률
  - 최대 낙폭(MDD)
  - 거래 횟수
  - 평균 보유 기간

### 고도화

- 서버 기반 백테스트 실행
- 웹소켓 기반 실시간 시세 수신
- 조건 충족 시 푸시 알림
- 사용자별 전략 저장
- 알림 이력 관리

## 우선순위

1. 차트 지표 토글 구조 완성
2. 실제 시세 API 연결
3. 이미지 분석 결과와 실제 지표 계산값 연결
4. 포트폴리오 베타 계산
5. 상관관계 매트릭스
6. 백테스트 조건식 빌더
7. 웹소켓 실시간 알림

## 기술 방향

- 앱: React Native / Expo
- 차트 렌더링: 현재 SVG 기반, 고성능 구간에서 Skia 검토
- 분석 로직: 클라이언트에서 MVP 구현 후 서버로 이전 가능
- 실시간 처리: WebSocket + Push Notification
- 데이터 저장: 초기 로컬 저장, 이후 사용자 계정 기반 서버 저장

## 주의사항

- 앱 내 전략 결과는 투자 참고용 시나리오로 표현한다.
- 특정 종목 매수/매도 권유처럼 단정하는 문구는 피한다.
- 실시간 시세 API 약관, 지연 시세 표시 의무, 금융 고지 문구를 별도로 검토한다.
